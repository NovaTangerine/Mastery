KEY · Decisions, assumptions, open questions

Capsule · Lo-fi set — how to read it

Low fidelity on purpose: structure and purpose only. Visual style, motion and the collectible look are left open.

Decided

• Web first, mobile soon

• Profile = Home at launch: bio, socials, Top 5, showcase (10/16/25); the rest in All games

• Growth at launch = sharing links off-platform; F is the landing page

• Rating optional on every capsule; per-person main scale; other scales optional

• Capsule finished, dropped, or all-time favorites

• Edit after reveal; replay allowed

• Likes at launch; follow + mutual friends

• Favorite moment: text + screenshot; tags suggested + custom

• Top 5 set manually; rated & unrated look the same on the shelf

Assumed (check me)

• Rating scale lives in Settings (H)

• Dropped capsules hidden from discovery by default

• Link format capsule.gg/user/game is a placeholder

• Mobile: D1 collapses into D2-style steps; Share becomes a bottom sheet

Open

• A1 vs A2 for the profile

• D1 vs D2 for writing

• Unrated card: headline, verdict stamp, signature icon, or Play/Skip?

• Reveal sound

• Collectible form: card vs cartridge

• What creates delight on the game page?
