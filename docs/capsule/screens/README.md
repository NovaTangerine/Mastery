# Capsule wireframes (lo-fi)

Open any file in a browser. Each screen is a labeled frame; the beige strip at the top names it.

| File | Screens |
|---|---|
| `01-lofi-set.html` | A1/A2 Capsule page (profile = home), B All games, C New capsule, D1/D2 Write (one page vs stepped), E1/E2 Reveal (rated/unrated), F Public capsule, G Share, H Settings, M1–M3 mobile, KEY decisions |
| `02-first-time-user.html` | S1 Landing → S2 Google sign-in → S3 Claim your Capsule → S4 Start your Capsule → S5 Fill your Top 5 → S6 Welcome moment |

Where they disagree, `02` and `03` are newer than `01` (the review flow in `03` supersedes D1/D2 and E1/E2).
